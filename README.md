# Requirements to Run

To run this Python application, make sure that you have Python installed on your machine. Also make sure that it is added to your system's PATH such that running the `python --version` command on any working directory would not lead to errors.

# How to Run

1. Open a terminal with `EmployeeAttritionSimulation` as the working directory
2. Run this command to install dependencies: `pip install -r requirements.txt`
    - **Fallback:** If the command gives an error, run this command instead:
        `pip install numpy pandas scipy scikit-learn matplotlib PyQt6`
3. Run the application: `python app.py`
